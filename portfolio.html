Other Software Projects

Wikipedia Search Engine

A search engine focused on Wikipedia pages. Creates embeddings for text and images using open source CLIP models, stored and queried via a vector database. All components are containerized with Docker for modular management.

Naturify

An iOS app for identifying plants, animals, and fungi from photos. Trained a visual transformer on 10,000 species using PyTorch on an Nvidia A100 GPU. Also includes a geolocation model that predicts nearby species from lat/lng coordinates.
